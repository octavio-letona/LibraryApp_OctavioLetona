Java y POO

Diferencia entre clase y objeto:
La clase es el molde o plantilla; el objeto es la instancia concreta creada a partir de esa clase.

¿Qué es un atributo?
Es una variable definida dentro de una clase que representa una característica o propiedad del objeto.

¿Qué es un método?
Es una función o bloque de código dentro de una clase que define el comportamiento y las acciones del objeto.

¿Para qué sirve un constructor?
Es un método especial que se ejecuta automáticamente al instanciar un objeto para inicializar sus atributos.

Diferencia entre private, public y protected:
public da acceso desde cualquier clase; private limita el acceso únicamente dentro de la misma clase; protected permite acceso dentro del mismo paquete y en sus subclases.

¿Para qué sirven get y set?
get sirve para obtener el valor de un atributo privado; set sirve para asignarle o modificar su valor de forma segura.

¿Qué significa encapsulamiento?
Es el principio de la POO que oculta el estado interno de un objeto restringiendo el acceso directo a sus atributos mediante modificadores de acceso.

Diferencia entre clase e interfaz:
La clase implementa atributos y métodos con lógica; la interfaz define un contrato de métodos abstractos (sin cuerpo) que las clases deben implementar.

¿Qué significa implements?
Es la palabra clave que indica que una clase va a cumplir y desarrollar los métodos definidos por una interfaz.

¿Qué significan static y final?
static hace que el miembro pertenezca a la clase y no a las instancias de forma individual; final vuelve inmodificable un valor (constante), evita la herencia de clases o la sobrescritura de métodos.

Base de datos y persistencia

¿Qué es una tabla relacional?
Es una estructura de almacenamiento organizada en filas (registros) y columnas (campos) vinculada con otras mediante claves.

¿Qué es una clave primaria?
Es el identificador único e irrepetible para cada registro dentro de una tabla.

¿Qué significa CRUD?
Acronimo de las operaciones básicas en bases de datos: Create (Crear), Read (Leer), Update (Actualizar) y Delete (Eliminar).

¿Qué es JDBC?
Java Database Connectivity: API estándar de Java para conectar y ejecutar consultas con bases de datos relacionales.

¿Qué es un procedimiento almacenado?
Un conjunto de instrucciones SQL guardado y compilado directamente en el servidor de base de datos para ejecutarse cuando sea invocado.

¿Qué es DAO?
Data Access Object: patrón de diseño que centraliza y aísla toda la lógica de acceso y manipulación de datos.

¿Por qué separar SQL del Controller?
Para cumplir con el principio de responsabilidad única, mantener un código limpio, reutilizable y desacoplar la interfaz gráfica de la base de datos.

JavaFX y arquitectura

¿Qué es JavaFX?
Un framework y conjunto de paquetes de Java para crear interfaces gráficas de usuario (GUI) avanzadas.

¿Qué es FXML?
Un lenguaje de marcado basado en XML utilizado en JavaFX para definir la estructura de la interfaz gráfica de forma declarativa.

¿Qué función cumple SceneBuilder?
Herramienta visual e interactiva que permite diseñar interfaces FXML arrastrando componentes gráficamente sin escribir XML manualmente.

¿Qué es un Controller?
Clase de Java que contiene la lógica de interacción de la vista FXML, procesando los eventos ejecutados por el usuario.

¿Qué significa MVC?
Model-View-Controller (Modelo-Vista-Controlador): patrón de arquitectura que separa la aplicación en datos/lógica de negocio, interfaz gráfica y control.

¿Qué responsabilidad tiene el modelo?
Gestionar la información, las reglas de negocio y la comunicación con la persistencia/base de datos.

¿Qué responsabilidad tiene la vista?
Mostrar la interfaz visual al usuario y capturar los eventos o entradas de datos.

¿Qué responsabilidad tiene el controlador?
Recibir las acciones de la vista, invocar la lógica del modelo y actualizar la vista con las respuestas.
